To use the openSSL dependency in Visual Studio quickly, you can use thee commands:

<code>git clone https://github.com/Microsoft/vcpkg.git</code>

<code>cd vcpkg</code>

<code>./vcpkg integrate install</code>

<code>./bootstrap-vcpkg.bat</code>

<code>./vcpkg install zlib</code>

<code>./vcpkg install boost-iostreams</code>

<code>./vcpkg install boost-system boost-thread</code>

<code>./vcpkg install openssl:x64-windows</code>

<code>./vcpkg install boost</code>

<code>./vcpkg install boost-beast</code>

You also need to add the

<code>path_to_your_vcpkg\installed\x64-windows\include</code>

<code>path_to_your_vcpkg\installed\x64-windows\lib</code>

to your IDE dependency

For example, my path is

<code>E:\vcpkg-master\installed\x64-windows\include</code>

<code>E:\vcpkg-master\installed\x64-windows\lib</code> 


The key.pem and cert.pem can be generated by:
<code>openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes


The root-key.pem can be generated by:

<code>openssl genrsa -out root-key.pem 4096



The root-cert.pem can be generated by:

<code>openssl req -x509 -new -nodes -key root-key.pem -sha384 -days 3650 \</code>

<code>  -out root-cert.pem \</code>

<code>  -subj "/C=CN/ST=Beijing/L=Beijing/O=Security Lab/CN=Global Security Root CA" \</code>

<code>  -addext "basicConstraints=critical,CA:TRUE,pathlen:0" \</code>

<code>  -addext "keyUsage=critical,keyCertSign,cRLSign" \</code>

<code>  -addext "certificatePolicies=1.3.6.1.4.1.4146.1.20" \</code>

<code>  -addext "subjectKeyIdentifier=hash" \</code>

<code>  -addext "authorityKeyIdentifier=keyid:always"</code>
